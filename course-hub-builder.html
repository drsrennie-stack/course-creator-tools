01

Course identity

Choose the course type. The hub adapts: Anatomy and Physiology each get 3 sections (R, H, O), Physiology adds a 4th (Anatomy refresher), and Anatomy & Physiology adds an Anat/Phys filter and tags every resource.

02

Course toolkit

Pick a category, add resources. Categories you don't fill stay hidden in the published hub. Use Bulk paste for many URLs at once.

03

Modules and topics

Each module has its own topics. Each topic has resources sorted into Required (R), Highly recommended (H), Optional (O), and for Physiology, Anatomy refresher (A). Empty modules and topics don't appear in the published hub.

Quick start Create empty modules at once

Download & deploy

One self-contained .html file with everything baked in. Upload to Kajabi as a custom HTML embed, host on GitHub Pages, or email it to a colleague. No build step, no dependencies, just a file.
